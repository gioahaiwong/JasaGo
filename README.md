\# 🛠️ JasaGo - Service Marketplace



A full-stack service marketplace where clients can order services from providers.



\## 🚀 Tech Stack



\- \*\*Backend:\*\* Node.js, Express, SQLite, JWT, bcrypt, node-cache

\- \*\*Frontend:\*\* React, Vite, TypeScript, Tailwind CSS, Framer Motion



\## ✨ Features



\- 🔐 Authentication (JWT + Cookie)

\- 👤 Role-based access (Client, Provider, Admin)

\- 🛠️ Service CRUD (Provider)

\- 📦 Order flow (Pending → Accepted → Completed)

\- 💳 Manual payment + admin verification

\- ⭐ Review \& rating system

\- 🤖 AI-powered recommendation system

\- ⚡ In-memory caching

\- 🧹 Auto-cleanup job
